BuggyBot · Reference

Semester 1 demo cheat sheet

Live recognition of printed US traffic signs on a Raspberry Pi CM5. The demo doesn't drive. Sources: the demo README and source.

Pipeline (each frame while searching)

  1. Capture: 1280×720 color frame from Camera Module 3.
  2. Propose: OpenCV marks colored pixels and edges, traces contours, and keeps up to 8 plausibly sized, roughly square regions.
  3. Classify: square crop (skipped if under 120 px), resized to 32×32 RGB, passed to the CNN, which returns a label and a confidence.
  4. Reject: keep only if confidence ≥ 0.85 and the color and shape match the label. Drop matches inside other matches.
  5. Confirm: same best label on 3 consecutive frames.
  6. Output: LCD shows the label and confidence for 3 s, then goes back to searching. Stream at http://buggybot.local:8000.

Glossary

Classifier
A model that assigns one of a fixed set of labels to the image it's given. It can't say "none of these."
Detector
A system that finds where objects are in a full image. BuggyBot builds one from proposals, a classifier, and checks.
Proposal
A region of the frame that OpenCV flags as possibly a sign, before any model sees it.
Contour
The traced outline of a blob of marked pixels.
Confidence
The classifier's score (0–1) for its top label. It measures certainty about which sign, not whether it's a sign.
CNN
Convolutional neural network: a model that learns visual patterns from labeled images.
LiteRT
Google's on-device runtime for .tflite models (formerly TensorFlow Lite).
CM5
Raspberry Pi Compute Module 5: a Raspberry Pi 5 as a plug-in module, used with a carrier board for its ports.
Confirmation
Requiring the same top label on 3 consecutive frames before showing it.
