# Notes

- Audience: people outside the project (advisor, judges, new members) who know
  basic software and computer engineering but nothing about BuggyBot.
- Lessons are written for them, not for the team. Define every project term on
  first use and avoid team shorthand.
- First lesson is an end-to-end overview; later lessons go deeper on one
  pipeline stage each.
- Link repository files with GitHub URLs in lessons so the HTML works when it
  is shared on its own.
